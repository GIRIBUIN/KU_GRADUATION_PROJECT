## 자료의 성격

| 위치 | 의미 | 유지 방식 |

`DB 재설계 비교와 적용안`, DB v6 관계도와 초기 검증은 **v6 도입 당시 기록**이다.
OCR 문서는 보류 중인 설계안이다. 현재 저장 구조는 DB v7 명세를 사용한다.

## 용어

- **할 일(Task)**: 개인/가져온 할 일을 같은 사용자 작업으로 관리한다.
- **폴더(FolderGroup)**: 목록을 묶는 한 단계의 그룹. 할 일이 직접 들어가지 않는다.
- **목록(List)**: 할 일이 반드시 하나 소속되는 공간. 내부 호환 이름 `Folder`/`FolderRepository`가 남아 있다.
- **미지정(Inbox)**: 기본 고정 목록. `kutodo:inbox`이며 임의 폴더에 넣지 않는다.
- **태그(Tag)**: 폴더·목록과 독립적으로 할 일에 복수 연결하는 분류.
- **eCampus 가져오기**: 학교 원본을 읽어 로컬 작업과 비교·반영하는 현재 기능. 코드의 `sync`는 이 의미다.
- **기기 간 동기화**: 여러 기기의 사용자 데이터를 맞추는 별도 보류 과제.

파일명은 학기 자료에 `KUTODO_연도_학기_자료명`, dated 기록에 `내용 YYYY-MM-DD`를 사용한다.
기존 증거 파일명은 해시·링크·실행 기록을 보존하기 위해 바꾸지 않는다.
