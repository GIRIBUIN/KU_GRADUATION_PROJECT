# main 통합 및 브랜치 정리 — 2026-11-15

현재 개발 브랜치는 **원격·로컬 모두 main 하나**다. 기존 통합 브랜치의 검증된 snapshot `2ceb2f1`을 main에 fast-forward했다. DB v7·UI·팀원 Android 위젯·서브 작업까지 포함하며 기존 commit 이력을 보존한다.

- 기존 원격 main: `3df50dd` → 검증된 통합본 `2ceb2f1`.
- 삭제: 작업 당시 남아 있던 원격 브랜치 9개, 로컬 작업 브랜치 6개.
- 보존: 삭제 전 각 tip을 annotated archive tag 15개로 만들고 원격에 push한 뒤, 모든 tag의 실제 commit SHA와 main을 확인했다. 기존 tag도 유지했다.
- 별도 iOS·위젯 개발본과 `feature/test`의 문서 이력은 보관 tag에서 복구할 수 있다. 검증된 최신 앱 코드에 별도 개발본을 추가로 섞지 않았다.
- 원격 삭제는 atomic push와 각 branch SHA에 대한 lease로 보호했다. 로컬은 archive SHA 확인 후 일반 `git branch -d`를 사용했다. 강제 로컬 삭제는 하지 않았다.
- 오래된 remote-tracking ref는 `git fetch origin --prune`으로 정리했다.

이후 main에 추가하는 commit은 이 정리 문서·검증 기록뿐이다. 앱 코드는 검증·S24 설치한 통합본과 동일하며, branch 정리 때문에 테스트·빌드·설치를 반복하지 않았다. [정리 결과 및 SHA 원본](evidence/integration/main-consolidation-result-20261115.json).
