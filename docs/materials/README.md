## 현재 문서와 함께 읽기

1학기 계획서의 세션 암호화 저장·자동 수집 구상과 2학기 미팅의 장기 로그인/주기 조회 실험은 현재 main의 정책과 구분한다.
현재는 사용자 요청 기반 가져오기와 처리 후 세션 정리이며 [보안 정책](../보안%20정책.md)에 정리했다.
당시 계획한 DB 개선·검증·문서화가 어떻게 진행됐는지는 [개선 작업 기록](../개선%20작업%20기록.md)과 [검증 및 측정](../검증%20및%20측정.md)을 본다.

미팅 자료 11~14장에는 최정길의 연동·세션·재현/검증·문서화 범위가, 16장에는 당시 R&R이 있다.
역할 분담은 회의 당시 계획이며 모든 팀원의 현재 완료 상태를 증명하지 않는다.

`output/presentation/`의 별도 발표 초안·시각자료와 `.meeting-*`/`.presentation-build` 작업 폴더는 로컬 작업물로 그대로 두었다.
이번 정리에서 이를 제출 정본으로 승격하거나 삭제하지 않았다.
