# 홈·캘린더 연결 명세

현재 기준: 2026-11-15. 하단 캘린더 아이콘으로 진입하며 예전 설정의 홈 구성에서 켜는 흐름을 현재 안내로 사용하지 않는다.

- 전체 폭 월/주 선택, 오늘·이전·현재 기간·다음·추가 버튼을 사용한다.
- 선택 날짜의 목록과 고정 할 일/보기 조정 줄을 제공한다. 별도 일정 사본이나 외부 캘린더 동기화는 없다.
- Task.dueDate의 기기 현지 날짜로 분류하며 active/completed만 보여준다. deleted/excluded는 제외한다.
- 미완료 우선·마감 정렬, 개인/eCampus 유형과 완료 표시 조정, 날짜 미지정 작업을 제공한다.
- 생성은 기존 TaskCreateScreen을 열고 선택 날짜 23:59를 초기 마감으로 전달한다.
- 공통 행의 우선순위 배경·D-day/시간·목록/태그·서브 펼치기와 긴 제목 줄바꿈을 재사용한다.
- 터치는 서브가 있으면 펼치기/접기, 없으면 상세. 길게 누르기는 바로 상세 Bottom Sheet다. 예전 편집/삭제 컨텍스트 메뉴는 제거됐다.
- 부모 완료/해제는 기존 Task·알림·위젯 콜백을 사용한다. 서브 체크는 기존 SubTask 저장소를 사용하고 부모 자동 완료는 하지 않는다.
- MainShell의 메모리 버전으로 서브 변경을 홈·캘린더 캐시에 전달하고 상세 편집 뒤에는 다시 조회한다.
- 선택 날짜·월/주·캘린더 필터는 해당 화면 메모리 상태다. 홈의 저장된 기간·보기 설정과 구분한다.
