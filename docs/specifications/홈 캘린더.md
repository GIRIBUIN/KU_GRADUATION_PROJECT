# 홈 캘린더

## 진입과 표시

- 설정 > 홈 표시 > 홈 화면 구성에서 캘린더를 켜고 저장한다.
- 캘린더는 기본 숨김이며 기존 섹션과 함께 순서를 변경할 수 있다.
- 월/주 전환, 이전/다음 기간, 오늘 이동, 연월 버튼의 날짜 선택을 제공한다.
- 날짜별 표시점은 개인 일정(파랑), e-campus 일정(초록)을 구분한다.
- 개인/e-campus 유형 필터와 완료 일정 표시/숨김을 제공한다.

## 데이터 기준

- 기존 Task 저장소를 그대로 사용한다. 별도 일정 사본이나 외부 캘린더 동기화는 만들지 않는다.
- 마감일 `Task.dueDate`의 기기 현지 날짜에 일정을 표시한다.
- `active`, `completed` 항목을 표시하며 `deleted`, `excluded` 항목은 제외한다.
- 완료 일정은 기본 포함하며 날짜별 목록에서는 미완료, 완료 순으로 표시한다.
- 날짜가 없는 작업은 '날짜 미지정' 목록에 표시한다. 상세 화면에서 날짜를 지정하면 달력에 나타난다.
- e-campus 일정은 기존 동기화로 가져온 Task를 표시한다. 캘린더가 e-campus에 별도로 로그인하거나 원격 정보를 변경하지 않는다.

## 추가·수정·완료·삭제

- 날짜 선택 후 추가 버튼을 누르면 기존 새 작업 화면을 연다. 선택 날짜의 23:59가 마감일 초깃값이며 사용자가 변경할 수 있다.
- 제목, 메모, 태그, 알림, 하위 작업 등 기존 작성 기능을 그대로 사용한다.
- 일정 선택 또는 메뉴의 수정으로 기존 상세 화면을 연다.
- 체크박스는 기존 완료/미완료 처리 및 알림 갱신을 호출한다.
- 메뉴의 삭제는 기존 삭제된 작업 목록으로 이동시키며 영구 삭제하지 않는다.
- 추가·수정·완료·삭제 후 홈 데이터와 Android 위젯 갱신 흐름을 재사용한다.
- 작업과 홈 섹션 구성은 기존 SQLite에 저장된다. 선택 날짜, 보기 형식, 필터는 화면 내 상태다.

## 구현 위치와 검증

- `lib/data/services/calendar_task_index.dart`: 날짜별 작업 분류 및 필터.
- `lib/presentation/widgets/home_calendar_section.dart`: 캘린더와 날짜별 목록.
- `lib/presentation/screens/main/main_shell_screen.dart`: 기존 작업 흐름 연결.
- `test/data/services/calendar_task_index_test.dart`: 날짜·시간대·상태·유형 분류.
- `test/presentation/widgets/home_calendar_section_test.dart`: 날짜 선택, 보기 이동, 필터, 화면 크기.
- `test/presentation/screens/main_shell_home_layout_test.dart`: 홈 편집 및 작업 추가·수정·삭제 통합 동작.
