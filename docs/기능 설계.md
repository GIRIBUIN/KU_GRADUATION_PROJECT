# KUTODO 기능 설계

현재 구현 기준: 2026-11-15 / main / DB v7. [학기별 계획 자료](materials/README.md)는 당시 계획이며 완료 기능 표가 아니다.

## 할 일과 분류

- 개인 할 일과 eCampus에서 가져온 할 일을 생성·조회·수정·완료·삭제·복원한다.
- 할 일은 **목록 하나**에 필수 소속된다. 목록은 상위 폴더에 들어가거나 폴더 밖에 있을 수 있다.
- 폴더는 목록만 묶는다. 폴더 중첩·목록 중첩·할 일의 복수 목록 소속은 지원하지 않는다.
- 태그는 전역이며 할 일에 복수 연결한다. 태그를 폴더 안에 배치하는 기능은 현재 UI에서 사용하지 않는다.
- 기본 목록은 **미지정**이다. Drawer 목록 구역의 첫 행에 고정되고 이름 변경·폴더 이동·삭제를 막는다.
- 완료·휴지통 전환과 복원은 목록 소속을 유지한다. 폴더 삭제는 안의 목록을 폴더 밖으로 옮긴다.
- 목록·태그는 Drawer에서 생성·편집·순서 변경·숨김을 관리한다. 목록 보관/복원 메뉴는 제거했고 숨김을 사용한다.

## 홈·캘린더

Drawer는 볼 범위, 상단은 날짜/기간, 보기 조정 Bottom Sheet는 정렬·필터를 담당한다.
선택 기간·마감 임박·마감 지남·완료를 평평한 목록 섹션으로 표시한다.

- 조회 기간: 오늘 / 이번 주 / 이번 달 / 기간 선택(단일 날짜·구간). 마지막 선택을 저장한다.
- Drawer 전체: 날짜 제한 없이 조회한다. 기간 선택 메뉴에 전체를 중복으로 두지 않는다.
- 정렬: 기본·마감 빠른 순·마감 늦은 순·최근 생성·우선순위.
- 필터: 상태·우선순위·태그. 변경은 즉시 반영하며 저장한 보기 설정만 재실행 때 복원한다.
- 마감 임박·마감 지남은 실제 현재 시각과 설정 기준으로 판정한다. 선택 기간의 첫 섹션과 별도로 같은 범위에서 조회한다.
- 캘린더는 월/주 보기와 선택 날짜의 할 일을 표시하고 같은 생성·상세·완료 흐름을 사용한다.

공통 행은 제목을 줄바꿈하고 `폴더 > 목록 · #태그`를 표시한다.
우선순위는 화면 전체 폭의 연한 배경(높음 빨강·중간 주황·낮음 파랑), 마감은 `D-N`/`D+N`/`D-day`와 시간 두 줄이다.
서브 작업이 있으면 터치로 펼치고 접으며, 없으면 상세를 연다. 길게 누르면 기존 상세 Bottom Sheet를 연다.
서브 작업은 체크박스·제목만 표시하고 모두 완료해도 부모를 자동 완료하지 않는다.

## eCampus 가져오기

사용자가 상단 가져오기 버튼을 누르면 WebView 로그인·HTML 조회·파싱·비교·검토를 거쳐 선택을 저장한다.
신규 항목은 가져오기/제외, 변경 후보는 제목·마감일 각각 원본 적용/현재 값 유지가 가능하다.
메모·목록·태그·우선순위 등 사용자 값은 변경 후보 반영 때 보존한다.

원본에서 보이지 않는 미완료 항목은 MISSING 검토로 분리하고 **유지(기본) / 완료 / 삭제**를 선택한다.
불완전 응답·파싱 오류는 누락 판정에 사용하지 않는다. 자동 완료·자동 삭제하지 않는다.
신규 기본 배치는 `eCampus 폴더 → 과목 목록 → 할 일`이며 검토에서 다른 목록을 지정할 수 있다.
현재 검토는 별도 화면이다. 결과 Bottom Sheet는 후속 설계다.

## 휴지통·제외 항목

- 휴지통: 행/체크박스로 선택하고 복원·영구 삭제한다. 기본 기간은 별도의 전체이며 정렬/필터는 이 범위의 임시 설정이다.
- 제외된 eCampus 항목: 가져오지 않는 원본을 같은 목록 레이아웃에서 선택·제외 해제한다. 해제 즉시 Task가 생기는 것이 아니라 다음 가져오기에서 다시 후보가 된다.
- 두 범위의 행 터치는 상세/서브 펼치기 대신 선택이다.
- 현재 저장소는 사용자 요청 시 영구 삭제를 수행한다. 예전 문서의 일괄적인 7일 보관 제한을 현행 기능으로 설명하지 않는다.

## 알림·Android 위젯

알림은 마감 N분 전 규칙을 사용하고 규칙과 OS 예약 결과를 분리해 저장한다.
eCampus로 마감이 바뀐 경우 기존 enabled 설정이 있을 때만 commit 후 재예약한다.
완료·삭제 시 취소, 재활성화 시 기존 예약 경로를 사용한다.

오늘/이번 주 위젯은 페이지로 전체 대상 작업을 보여주며 완료·해제, 목록 선택 빠른 추가, 자정 갱신을 지원한다.
위젯에는 소속 목록명·색상만 표시하고 태그·폴더 경로·미지정 라벨은 생략한다.
현재 네이티브 위젯은 Android 대상이다.

기기 간 동기화·OCR·장기 로그인·주기적 eCampus 조회·사용자 평가 완료는 현재 구현으로 간주하지 않는다.
