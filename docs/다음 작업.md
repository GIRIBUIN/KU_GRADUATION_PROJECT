## 0. 먼저 확인한 가져오기 표시·과목 목록 문제

- 기기 DB 확인: 원본 11개가 모두 Task에 연결돼 있고 미완료 eCampus Task 6개도 저장되어 있었다. 제목·메모·쿠키·원본 HTML은 기록하지 않았다.
- ‘전체 일정 관리’는 날짜 제한이 없고, 홈의 기존 ‘전체’ 메뉴는 상단 ‘오늘’ 조건을 유지하고 있었다. 전체 기간 선택을 추가하고 첫 메뉴 이름을 오늘/이번 주/이번 달/전체로 바꿔 실제 기간을 나타낸다. 특정 날짜는 그 날짜로 표시한다.
- 가져온 항목에 현재 저장 목록과 ‘할 일 보기’를 표시한다. 이미 가져온 항목도 실제 Task ID로 열 수 있다.
- 기존 v6 항목은 미지정 소속으로 보존돼 신규 과목 목록 생성 경로를 타지 않았다. 사용자는 **미지정의 미완료 6개만 과목 목록으로 이동**하는 안을 선택했다. 검토 화면의 ‘과목별 정리’는 eCampus 폴더·과목 목록을 기존 생성 경로로 준비하고 검토한 미완료·미지정 항목만 옮긴다. 완료·휴지통·수동 분류는 유지하고 전체 처리를 transaction으로 묶는다.
- 실제 기기의 정리 실행·설치 결과는 별도 검증 기록을 기준으로 한다. ‘현재 코드가 지원함’과 ‘기기에서 실행됨’을 구분한다.

## 5. Task 좌우 스와이프 설정 — 홈 구현 완료

- 설정에 편집 화면을 두고 왼쪽→오른쪽/오른쪽→왼쪽 동작을 지정.
- 일반 Task 후보: 삭제, 편집, 완료.
- 휴지통 후보: 복원, 영구 삭제. 일반 Task 설정과 분리.
- 설정 → 편집 → 스와이프 동작에서 네 방향을 별도로 저장한다. 기본값은 일반 오른쪽 완료/해제·왼쪽 삭제, 휴지통 오른쪽 복원·왼쪽 영구 삭제다. 영구 삭제는 확인창을 재사용한다.

- 휴지통 정렬/필터는 홈과 별도 메모리 상태이며 저장 버튼 없이 즉시 적용한다. Drawer 범위 또는 하단 탭을 바꾸면 초기화한다. 관련 화면 42건 통과. [화면·검증·실기기 확인](evidence/home-ui/README.md#휴지통-선택-작업임시-보기--2026-10-31). 설치·커밋은 미수행이다.

## 7. eCampus 가져오기 진입 간소화 — 구현 완료

- 현재 가져오기 버튼→중간 진행 화면→WebView 흐름 중 불필요한 중간 화면 정리.
- WebView 로그인·조회·검토·반영·세션 종료·실패 안내는 보호.
- 단계 카드가 있는 중간 UI와 별도 로그인 push를 제거했다. 같은 가져오기 경로 안에서 WebView 로그인 → 조회 로딩 → 기존 검토로 이어진다. 취소 시 세션 정리 후 복귀하고 실패 재시도는 다시 로그인한다.
- 관련 화면 60건 통과, 세션 참조 해제 뒤 eCampus 22건 재확인 통과. [변경·검증·실기기 확인](evidence/home-ui/README.md#ecampus-가져오기-진입-간소화--2026-10-31). 실제 WebView 로그인·기기 설치·이번 변경 커밋은 미수행이다.

## 8. 기간별 마감 임박·마감 지남 기준 재검토 — 점검 완료

- 현재 두 보조 섹션은 선택 기간과 별개로 실제 현재 시각을 기준으로 계산한다.
- 기존 합의대로 첫 섹션/완료는 선택 기간, 임박/지남은 실제 현재 기준을 유지했다. 임박은 오늘 제외 D+1~설정한 D+N 날짜 전체, 지남은 마감 시각이 실제 현재보다 이전인 미완료 항목이다. 완료는 completedAt을 우선 사용한다.
- 앱 로직 수정 없이 경계·기간 변경 회귀 5건을 보강했다. 관련 테스트 46건 통과. [점검 결과·원본](evidence/home-ui/README.md#기간별-마감-임박지남-기준-점검--2026-10-31). 다음 문구 작업은 별도 범위다.

## 9. 빈 목록 문구 — 구현 완료

- ‘표시할 할 일이 없습니다’ 등에서 ‘표시할’을 제거.
- 홈은 ‘할 일이 없습니다.’, 전체 일정 관리는 ‘일정이 없습니다.’로 변경했다. 두 화면을 확인하는 기존 UI 테스트 1건 통과. [검증 기록](evidence/home-ui/README.md#빈-목록-안내-문구--2026-10-31).
