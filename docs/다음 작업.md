## 0. 먼저 확인한 가져오기 표시·과목 목록 문제

- 기기 DB 확인: 원본 11개가 모두 Task에 연결돼 있고 미완료 eCampus Task 6개도 저장되어 있었다. 제목·메모·쿠키·원본 HTML은 기록하지 않았다.
- ‘전체 일정 관리’는 날짜 제한이 없고, 홈의 기존 ‘전체’ 메뉴는 상단 ‘오늘’ 조건을 유지하고 있었다. 전체 기간 선택을 추가하고 첫 메뉴 이름을 오늘/이번 주/이번 달/전체로 바꿔 실제 기간을 나타낸다. 특정 날짜는 그 날짜로 표시한다.
- 가져온 항목에 현재 저장 목록과 ‘할 일 보기’를 표시한다. 이미 가져온 항목도 실제 Task ID로 열 수 있다.
- 기존 v6 항목은 미지정 소속으로 보존돼 신규 과목 목록 생성 경로를 타지 않았다. 사용자는 **미지정의 미완료 6개만 과목 목록으로 이동**하는 안을 선택했다. 검토 화면의 ‘과목별 정리’는 eCampus 폴더·과목 목록을 기존 생성 경로로 준비하고 검토한 미완료·미지정 항목만 옮긴다. 완료·휴지통·수동 분류는 유지하고 전체 처리를 transaction으로 묶는다.
- 실제 기기의 정리 실행·설치 결과는 별도 검증 기록을 기준으로 한다. ‘현재 코드가 지원함’과 ‘기기에서 실행됨’을 구분한다.

## 1. Drawer 숨김 관리와 길게 누르기

- 숨김 버튼에서 목록들을 보여주고 개별 숨김 활성/비활성 편집.
- 폴더 길게 누르기: 폴더 편집, 해당 폴더에 목록 추가.
- 목록 길게 누르기: 목록 편집, 그 목록에 할 일 추가.
- 태그 길게 누르기: 태그 편집, 그 태그가 지정된 할 일 추가.

## 2. 홈에서 Drawer를 여는 제스처 범위

- 현재 왼쪽 가장자리에서만 열리는 제스처를 화면 안쪽에서도 가능하게 조정.
- 세로 스크롤·체크박스·행 스와이프와 충돌하지 않는 범위를 검증.

## 3. Task 상세를 Bottom Sheet로 변경

- Task 탭 시 별도 상세 페이지 대신 하단 Bottom Sheet.
- 기존 저장·완료·알림·위젯 처리와 상세 편집 기능 재사용.

## 4. Task row 표시

- 제목 글씨를 현재보다 2단계 작게 조정.
- 제목을 말줄임표로 자르지 않고 다음 줄로 이어 표시. 제목 길이에 따라 행 높이 증가.
- 분류는 `폴더 > 목록 · #태그1 · #태그2`처럼 경로와 태그를 구분.

## 5. Task 좌우 스와이프 설정

- 설정에 편집 화면을 두고 왼쪽→오른쪽/오른쪽→왼쪽 동작을 지정.
- 일반 Task 후보: 삭제, 편집, 완료.
- 휴지통 후보: 복원, 영구 삭제. 일반 Task 설정과 분리.

## 6. 휴지통 선택 작업과 임시 정렬

- 여러 항목 선택 후 선택 삭제/선택 복원.
- 휴지통 내부에서만 적용하는 일시적 정렬. 홈의 영구 보기 설정과 분리.

## 7. eCampus 가져오기 진입 간소화

- 현재 가져오기 버튼→중간 진행 화면→WebView 흐름 중 불필요한 중간 화면 정리.
- WebView 로그인·조회·검토·반영·세션 종료·실패 안내는 보호.

## 8. 기간별 마감 임박·마감 지남 기준 재검토

- 현재 두 보조 섹션은 선택 기간과 별개로 실제 현재 시각을 기준으로 계산한다.
