# eCampus 데이터 수집 및 가공

기준일: 2026-11-15. 현재 입력 방식은 인증된 세션의 체크리스트 HTML이며 OCR은 보류 설계다.

## 입력과 파싱

[HttpEcampusTodoClient.fetchTodoHtml](../lib/data/services/http_ecampus_todo_client.dart)는
`/ilos/mp/todo_list.acl`에 세션 Cookie와 `STYPE=1`을 넣어 POST한다.
HTTP 오류와 로그인 화면 응답은 정상 할 일 목록으로 취급하지 않는다.

[EcampusTodoParser.parse](../lib/data/services/ecampus_todo_parser.dart)는 `div.todo_wrap`을 순회한다.
제목·과목명과 원본 식별 인자에서 ParsedEcampusTask를 만들고 실패 목록을 별도로 반환한다.
`sourceKey = rawLectureId:rawItemId:rawType`이며 원본 HTML의 단일 필드명이 아니다.
이 세 값이 없으면 임의의 제목/마감 조합 키를 만들어 합치지 않는다.

| 파싱 값 | 사용자 작업 / 원본 저장 |
| --- | --- |
| title | 신규 Task.title, EcampusItems.sourceTitle |
| dueDate | 신규 Task.dueDate, EcampusItems.sourceEndAt |
| course/type | 원본 과목·유형. 현재 사용자 메모에 덮어쓰지 않음 |
| sourceKey | 원본 `(sourceScopeId, externalKey)` 식별 |

조회된 항목은 preview 단계에서 Task로 저장하지 않는다.

## 비교와 선택

- 신규: 같은 sourceKey의 기존 비교 대상이 없다. 가져오기 또는 원본 제외를 선택한다.
- 변경: 기존 미완료 항목의 원본 제목·마감·과목·유형 중 하나가 이전 원본 snapshot과 다르다.
- 변경 후보의 제목과 마감은 각각 원본 적용/현재 값 유지로 선택한다.
- 완료·삭제·이미 가져온·제외 항목은 별도로 분류한다.
- 신규 가져오기의 기본 목록은 강의 식별값별 과목 목록이며 미지정·다른 목록을 명시할 수도 있다.
- 신규 제외는 원본 ignored만 저장한다. 기존 Task의 현재 값 유지는 제외 상태로 전환하지 않고 원본 snapshot을 갱신한다.

## 누락 판정

classifier는 기존 eCampus 미완료 sourceKey와 이번 parsed sourceKey의 차집합을 MISSING 후보로 만든다.
`parseResult.isComplete && !hasFailures`일 때만 감지하며 중복 식별자·잘린 HTML·실제 추가 페이지 표시 등은 누락 판정을 막는다.
정상적인 no_data 응답과 구조를 확인할 수 없는 빈/오류 응답을 구분한다.

누락의 기본 선택은 유지이며 완료·휴지통 이동은 사용자가 선택한다.
부분 조회에서도 유효하게 파싱된 항목은 가져올 수 있지만 누락 전체 처리는 하지 않는다.
이 검사는 현재 응답 구조의 방어 조건이지 학교 전체 일정 수집을 외부에서 증명하는 기능은 아니다.

## 반영

현재 Drift 경로의 선택 batch는 transaction으로 저장한다. 한 항목 실패 시 DB 변경 전체가 rollback된다.
미리보기 이후 Task의 ID·상태·제목·마감·메모·우선순위·태그·목록이 바뀌었으면 다시 조회하도록 막는다.
제목·마감 이외의 사용자 값은 보존하고, 완료·삭제 항목을 무조건 원본 값으로 되돌리지 않는다.
반영 성공 시 ImportSessions에 기록하며 이 테이블은 로그인·취소·실패 전체 추적을 구현한 것이 아니다.

DB commit이 끝난 뒤 기존 enabled 알림의 마감 변경을 재예약한다. 후처리 실패가 성공한 DB transaction을 되돌리지는 않는다.
정확한 호출 위치는 [eCampus 상세 명세](specifications/e-campus%20동기화%20명세.md)를 참고한다.
