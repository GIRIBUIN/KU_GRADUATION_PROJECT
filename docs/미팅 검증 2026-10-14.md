# 2026-10-14 미팅 사전 검증

검증일: 2026-10-12. Android 기준으로 캘린더와 오늘·주간 홈 위젯을 통합했다.

## 브랜치와 범위

- 검증 브랜치: `test/meeting-calendar-widget-20261014`
- 기준: `main`의 `52e5a3d`
- 캘린더: `origin/calendar2`의 `534f0d2`까지 병합
- 위젯: `origin/feature/homewidget-weektask`의 `517dc14`까지 병합
- 캘린더 브랜치에 위젯 후속 변경 내용도 이미 포함돼 있었으며, 위젯 브랜치 병합으로 이력도 연결했다.
- 추가 수정은 아래 빌드 호환성과 위젯 복귀 문제 두 건에 한정했다.

## 발견한 문제와 수정

1. `table_calendar 3.3.0`의 `intl ^0.20.3` 요구가 Flutter SDK의 `intl 0.20.2` 고정과 충돌해 패키지 설치에 실패했다. 캘린더 제약을 `^3.2.1`로 변경하고 잠금 파일을 갱신했다.
2. 주간 위젯에서 완료·해제 후 앱에 복귀하면 DB 상태와 캘린더 체크박스가 달랐다. 위젯의 대기 변경을 DB에 반영한 뒤 화면을 다시 읽도록 순서를 수정했다. 완료·해제 회귀 테스트는 수정 전에 실패하고 수정 후 통과했다.

## 미팅 시연

1. `설정 → 홈 화면 구성 → 캘린더`를 켜고 저장한다. 검증 기기에서는 켜 둔 상태다.
2. 홈의 캘린더에서 날짜를 선택한 뒤 `+`로 일정을 추가한다. 선택 날짜의 23:59가 기본 마감이다.
3. 오늘 마감으로 생성하면 오늘 위젯과 주간 위젯에서 볼 수 있다.
4. 주간 위젯에서 완료·해제하고 앱을 열어 캘린더와 상태가 같은지 확인한다. 오늘 위젯은 완료 처리만 지원한다.

iOS 빌드와 실제 e-campus 재로그인·신규 동기화는 이번 검증 범위에 포함하지 않았다. 기기 백업과 UI 검증 자료는 Git에서 제외되는 `build/meeting-validation/`에 보관했다.
