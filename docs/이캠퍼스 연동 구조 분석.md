# eCampus 가져오기 호출 흐름

현재 Flutter main 코드 기준: 2026-11-15. 기기 간 동기화와 별개인 **로컬 가져오기** 흐름이다.

```text
MainShellScreen._openEcampusSync
→ EcampusSyncProgressScreen._startSync
→ WebView 로그인·EcampusSession
→ DefaultEcampusSyncFlowService.preview
→ DefaultEcampusSyncService.previewSync
→ DefaultEcampusTodoService.fetchAndParse
→ HttpEcampusTodoClient.fetchTodoHtml → EcampusTodoParser.parse
→ EcampusSyncClassifier.classify
→ EcampusSyncPreviewScreen에서 선택
→ DefaultEcampusSyncApplyService.importItems / excludeItems
→ DriftTaskRepository.atomic → Tasks / 원본 / 목록 / ImportSessions
→ commit 후 알림 후처리 → _finishSession
```

## 현재 정책

- 시작 시 쿠키를 정리하고 사용자가 로그인한다. 다음 실행에서 메모리 세션을 재사용하지 않는다.
- preview는 읽기 전용이며 NEW/CHANGED/MISSING은 사용자 검토를 거친다.
- 원본이 사라졌다는 이유만으로 자동 완료·자동 삭제하지 않는다.
- 같은 원본을 다시 선택해도 기존 Task를 중복 생성하지 않는 경로를 사용한다.
- 현재 값 유지와 신규 제외는 서로 다른 동작이다.
- 세션 정리는 반영 후와 정상/오류/취소/화면 해제에서 공통 함수로 처리한다.
- 설정에 별도 eCampus 로그인·세션·마지막 가져오기·수동 쿠키 정리 메뉴는 없다.

공식 외부 API, 계정 장기 저장, 주기적 자동 조회, OCR, 기기 간 동기화는 현재 경로에 포함되지 않는다.
필드별 반영과 원본 테이블 사용은 [상세 명세](specifications/e-campus%20동기화%20명세.md), 보안 범위는 [보안 정책](보안%20정책.md)을 본다.
