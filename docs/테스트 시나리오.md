# KUTODO 수동 테스트 시나리오

기준일: 2026-11-15. 아래는 **앞으로 실행할 체크리스트**이며 전 항목 통과 기록이 아니다.
자동 테스트·과거 실기기 결과와 환경은 [검증 및 측정](검증%20및%20측정.md)을 본다.
실행 결과는 날짜·기기/OS·commit 또는 APK 해시·재현 조건·기대/실제·수정/재검증으로 남긴다.

## 개인 할 일·분류

1. 제목만 빠른 추가하면 미지정에 저장되고, 목록/태그를 지정한 생성도 실제 저장되는지 확인.
2. 미지정이 Drawer 목록 구역 첫 행에 고정되고 이동·이름 변경·삭제되지 않는지 확인.
3. 폴더를 누르면 목록만 펼쳐지는지, 목록 안팎 이동과 순서 변경이 재실행 후 유지되는지 확인.
4. 같은 태그를 서로 다른 목록의 할 일에 연결하고 전체/목록/태그 범위의 조회가 맞는지 확인.
5. 완료·휴지통·복원 후 목록·태그·메모·원본 연결이 유지되는지 확인.

## 홈·캘린더·서브 작업

1. 기간과 Drawer 범위를 함께 바꾸고, Drawer 전체는 날짜 제한 없이 보이는지 확인.
2. 기간은 재실행 후 복원되며 저장한 보기 설정과 저장하지 않은 변경을 구분하는지 확인.
3. 배경이 전체 폭인지, D-N/D+N/D-day 위·시간 아래인지, 긴 제목/큰 글씨가 잘리지 않는지 확인.
4. 서브가 있는 행은 터치로 펼치고 접고, 없는 행은 상세를 여는지 확인. 길게 누르기는 둘 다 상세.
5. 서브 완료/해제 저장·홈↔캘린더 반영·상세 추가/삭제 후 갱신·저장 실패 재시도를 확인.
6. 모든 서브 완료가 부모 자동 완료로 이어지지 않는지 확인.
7. 캘린더 월/주·오늘·날짜 이동·선택 날짜 추가와 기존 완료/알림 연결 확인.

## 휴지통·제외 항목

1. 행과 체크박스로 선택되며 상세/서브 펼치기를 열지 않는지 확인.
2. 선택 상단·모두 선택/해제·뒤로가기, 선택 복원/영구 삭제·부분 실패 재시도 확인.
3. 휴지통은 별도 전체 기간으로 열리고 태그/우선순위 선택지가 휴지통 데이터에 맞는지 확인.
4. 제외 해제 후 즉시 Task가 생기지 않고 다음 가져오기에서 후보가 되는지 확인.

## eCampus 가져오기

| 상황 | 기대 결과 |
| --- | --- |
| NEW 가져오기 / 제외 | Task+원본 연결 생성 / ignored 원본만 저장 |
| 같은 원본 재조회 | 중복 Task 없음 |
| CHANGED 현재 값 유지 | 사용자 값 유지, 새 원본 snapshot 갱신 |
| 제목만 / 마감만 / 둘 다 적용 | 선택한 필드만 변경, 메모·태그·목록 보존 |
| 기존 enabled 알림이 있는 마감 변경 | commit 후 재예약; 설정 없으면 신규 예약하지 않음 |
| preview 후 사용자가 해당 Task 수정 | 검사 대상 필드 변경이면 반영 중단·다시 조회 |
| DB A,B / 완전한 이번 원본 A | 미완료 B가 MISSING, 기본 유지·완료·휴지통 선택 |
| 잘린 HTML·파싱 실패·실제 추가 페이지 | 누락 전체 처리 금지; 유효 파싱 항목의 가져오기는 별도 |
| 반영 중 한 항목 실패 | 현재 Drift batch 전체 rollback, 실패한 DB와 별개 OS 예약 변경 없음 |
| 정상 종료·실패·취소 | 앱 세션 참조와 eCampus WebView 쿠키 정리, 다음 실행 재로그인 |

## Android 위젯·알림

1. 오늘/주간 위젯을 여러 개 등록하고 각 페이지·크기·동일 마감 정렬을 확인.
2. 두 위젯과 앱의 완료·해제 일치, 삭제된 Task의 오래된 클릭으로 복구되지 않는지 확인.
3. 태그가 아니라 목록명·색상을 표시하고 미지정 라벨은 생략되는지 확인.
4. + 팝업에서 목록을 선택해 저장하고 기본 미지정·중복 탭·저장 실패 입력 보존을 확인.
5. 앱 종료·자정·재부팅·절전 환경의 갱신, 알림 권한·정확 알림과 예약 재계산을 확인.

계정·쿠키·세션·원본 HTML·기기 DB를 증거에 포함하지 않는다. 수집이 필요하면 비식별 합성 fixture로 재현한다.
