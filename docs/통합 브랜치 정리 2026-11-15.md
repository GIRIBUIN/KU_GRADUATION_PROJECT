# DB v7 앱·Android 위젯 통합 — 2026-11-15

사용자의 DB·목록·태그·홈 UI 개선과 팀원의 최신 Android 위젯 개선을 함께 사용하는 통합 작업이다. 기존 브랜치의 커밋 이력을 보존하는 merge 방식이다.

## 현재 상태

- 통합 브랜치: `integration/db-v7-widgets`. 이번 push 대상이며 main은 변경하지 않는다.
- 앱 기준: `refactor/flutter-db-v6` / `ea6f9a9480e80ed755bad1b975381dcf157bfd44`. 브랜치 이름은 v6지만 실제 앱 DB는 **v7**이다.
- 위젯 기준: `origin/main` / `3df50dd6fff9b5a197e45fdc1af6ef5d8b5437fd`. `feature/ImprovedHomeWidget`의 PR #12까지 포함한다.
- 공통 조상: `7fabd858d7d3acee03360e8e03d5186fa80326b3`.
- `git merge --no-commit --no-ff origin/main`으로 합친 뒤 충돌 해결·검증을 마쳤다. 통합 코드·테스트는 **`d629496` merge commit**으로 저장했고 양쪽 작업 이력을 보존했다.
- 검증·브랜치 정리·S24 설치 기록은 별도 문서 commit으로 나눈다. 사용자의 후속 요청에 따라 이 두 commit을 통합 브랜치에 push한다. 원격 main 갱신과 기존 브랜치 삭제는 이번 작업에 포함하지 않는다.

## 커밋 구성

| commit | 범위 |
| --- | --- |
| `d629496` — `merge: integrate database v7 app and widget updates` | 기존 두 브랜치 이력을 잇는 merge. 위젯 통합 코드, v7 호환 보완, 회귀 테스트 |
| `docs: record integration checks and branch cleanup` | 이 문서, 작업 기록·다음 작업, 테스트 원본·요약, S24 설치 기록 |

기존 앱·팀원 위젯의 개별 commit을 squash하지 않았다. `docs/evidence/integration/`의 통합 요약 JSON은 **merge commit 전 검증 시점의 snapshot**이고 S24 JSON도 설치 당시 상태다. 기록 속 `pending merge`는 현재 Git 상태를 뜻하지 않는다.

관련 없는 PPTX·이미지·output·임시 폴더는 stage하거나 commit하지 않았다. commit 직전에도 충돌 index 없음과 작업 트리·stage의 whitespace 검사를 확인했다. 검증 후 앱 코드를 추가 수정하지 않았으므로 테스트를 반복하지 않았다.

최종 개발 브랜치는 **main 하나**로 두는 것을 권장한다. 통합 commit과 기기 검증 이후, 원격 main에 새로운 작업이 추가되지 않았는지 먼저 확인한다. 이 기록의 main 상태가 그대로라면 로컬 main에서 다음 fast-forward가 가능하다.

```powershell
git switch main
git merge --ff-only integration/db-v7-widgets
```

이번 push는 통합 브랜치에 한정한다. **원격 main에 통합 commit이 실제로 올라간 것을 확인하기 전에는 원본 브랜치를 삭제하지 않는다.** 새 main commit이 추가됐다면 먼저 그 변경까지 통합·검증해야 한다.

`codex/ios-sideload-ipa`는 오래된 DB 기준의 별도 큰 작업을 포함한다. ‘모든 위젯 관련 브랜치’라는 이유로 그대로 합치지 않았다. 이번 통합 대상은 팀원이 최근 main에 반영한 `feature/ImprovedHomeWidget`이다.

로컬 `0r`, `backup-before-rollback`, `cal`, `test/meeting-calendar-widget-20261014`도 이번 두 부모 밖의 commit이 0개다. 최종 main 확인 후 삭제 후보다. 로컬 main은 유지한다. 임시 `integration/db-v7-widgets`도 main 반영을 확인한 뒤 정리할 수 있다.

`origin/feature/homewidget`, `origin/feature/homewidget-weektask`는 로컬에 남은 오래된 remote-tracking ref이며 실제 원격 브랜치 목록에는 없다. 실제 원격 브랜치 삭제 대상과 구분한다. 이번 fetch에서는 prune하지 않았다.

## 후속 S24 설치 — 2026-11-15

통합 debug APK를 빌드한 뒤 USB 디버깅으로 연결된 Galaxy S24(SM-S921N, Android 16)에 `adb install -r`로 설치했다. 설치 Success, MainActivity 실행 Status: ok, 앱 프로세스 실행을 확인했다. uninstall·데이터 삭제는 하지 않았다. 설치 전 이 패키지는 조회되지 않았으므로 이 기기에서 기존 DB 업그레이드를 검증한 것은 아니다. 화면·위젯·가져오기 동작은 사용자가 직접 확인할 예정이다. ## Android에서 직접 확인할 것

1. 기존 설치의 DB를 유지한 채 업데이트하고, 기존 개인/eCampus 할 일의 목록·태그·메모·완료·휴지통 상태가 유지되는지 확인.
2. 오늘/주간 위젯을 동시에 여러 개 배치하고 페이지 이동, 크기 변경, 같은 마감의 정렬 확인.
3. 각 위젯에서 완료·해제 후 다른 위젯과 앱에 반영되는지 확인. 앱에서 삭제한 할 일을 오래된 위젯으로 되살릴 수 없는지 확인.
4. 각 위젯의 +에서 팝업으로 생성하고 제목·마감·태그·미지정 목록 소속, 기존 앱 생성·알림 흐름 확인.
5. 앱을 닫은 상태의 자정 갱신, 재부팅·절전 후 갱신 확인. 기기별 백그라운드 제한은 단위 테스트로 입증되지 않는다.
6. 기존 홈/캘린더/Drawer와 eCampus 가져오기·검토·반영을 실제 계정으로 확인. 설계만 했던 결과 Bottom Sheet 개편은 이번에 구현하지 않았다.
