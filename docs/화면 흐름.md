# KUTODO 화면 흐름

기준일: 2026-11-15. 현재 공통 연결은 [MainShellScreen](../lib/presentation/screens/main/main_shell_screen.dart)이다.
예전 assets/mockups와 학기 자료는 당시 목업이며 최신 화면 캡처가 아니다.

## 주요 이동

하단은 **홈 아이콘 / + / 캘린더 아이콘**이다. 설정·별도 관리 탭은 없다.

| UI | 역할 |
| --- | --- |
| Drawer | 기간별 할 일·전체·목록·태그·완료·휴지통·제외 항목 선택 |
| 홈 날짜 영역 | 오늘·이번 주·이번 달·기간 선택 |
| eCampus 아이콘 | 기존 가져오기 흐름 실행 |
| 보기 조정 | Bottom Sheet에서 정렬·상태·우선순위·태그 선택 |
| + | 제목 중심 빠른 추가 Bottom Sheet, 필요하면 전체 입력으로 확장 |
| 캘린더 | 월/주·날짜 이동·선택 날짜의 생성/조회 |

Drawer 목록 구역의 첫 행은 미지정이다. 폴더를 누르면 안의 목록만 펼친다.
목록을 누르면 그 목록의 할 일을 조회한다. 목록/태그는 길게 눌러 편집 메뉴를 열고 드래그로 순서·소속을 바꾼다.
설정은 Drawer 하단의 컨텍스트 메뉴이며 스와이프·알림·마감 임박을 조정한다.
별도 설정 페이지, 전체 일정 관리 페이지, 목록 보관/복원 메뉴는 현재 진입점이 아니다.

## 할 일 행

```text
체크박스   제목(필요한 만큼 줄바꿈)            D-N / D+N / D-day
           폴더 > 목록 · #태그                HH:mm
```

우선순위는 행 전체 폭의 연한 배경으로 표시한다. 섹션 제목 옆 개수는 표시하지 않는다.
서브 작업이 있으면 작은 화살표가 나타나며 한 번 터치로 펼치고 접는다.
펼친 내용은 부모와 같은 배경 안의 들여쓴 체크박스·제목뿐이다.

- 서브 작업 없음: 터치 → 기존 상세 Bottom Sheet.
- 일반/완료 행 길게 누르기 → 상세 Bottom Sheet. 캘린더도 동일하다.
- 부모 체크박스 → 기존 완료/해제·알림·위젯 처리.
- 서브 체크박스 → 기존 SubTask 저장소에 완료/해제. 부모를 자동 완료하지 않는다.
- 상세에서 서브 작업을 편집한 뒤 돌아오면 새 내용을 조회한다.

## 휴지통·제외 항목

두 범위는 행 전체와 왼쪽 체크박스로 선택한다. 상세/서브 펼치기로 바꾸지 않는다.
선택하면 고정 상단의 뒤로가기·선택 수·복원/삭제 아이콘과 모두 선택/해제 줄을 사용한다.
휴지통은 복원·영구 삭제, 제외 항목은 제외 해제다.
휴지통의 기본 기간은 별도의 전체이며, 다른 범위의 기간·보기 설정과 분리된다.

## eCampus 가져오기

```text
상단 가져오기 → WebView 로그인 → HTML 조회·파싱·비교
→ 별도 동기화 미리보기 → 필드/항목/누락 검토 → 반영
→ 로그아웃·메모리/쿠키 정리 → 홈 갱신
```

시작할 때 이전 쿠키를 정리하고 매번 로그인한다. 오류·취소·화면 종료도 같은 정리 함수를 거친다.
결과를 Bottom Sheet로 바꾸는 구상은 아직 미구현이다.

## Android 홈 위젯

런처에서 오늘/이번 주 위젯을 등록한다. 완료·해제와 페이지 이동은 해당 위젯에서 처리한다.
+ 버튼은 공통 빠른 등록 팝업이며 제목·마감·소속 목록을 입력한다. 목록 미선택 기본값은 미지정이다.
위젯에는 태그 대신 목록명·색상만 보여주고 미지정 라벨은 생략한다.
