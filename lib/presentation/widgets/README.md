# 공통 UI

현재 기준: 2026-11-15.

task_list_row.dart가 홈·캘린더·완료·휴지통·제외 항목의 공통 행이다. home_calendar_section.dart는 캘린더와 선택 날짜 목록이다.

행 전체 우선순위 배경, D-day/시간, 긴 제목 줄바꿈, 목록/태그 경로를 사용한다. 서브가 있으면 터치로 펼치고 길게 누르면 상세를 연다. 휴지통/제외는 선택을 유지한다. task_metadata_picker.dart는 목록/태그 선택을 재사용하며 추가 콜백이 없으면 추가 버튼을 숨긴다.

전체 구조·정책·실행 방법은 [프로젝트 문서](../../../docs/README.md)를 본다.
